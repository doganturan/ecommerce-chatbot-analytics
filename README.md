# E-commerce Chatbot Analytics

MSc project analysing an e-commerce customer-support chatbot using the Bitext Customer Service Dataset.

## Analysis

- TF-IDF + Logistic Regression
- Intent classification and confusion matrix
- Confidence-based fallback
- User segmentation
- Linguistic robustness
- Frustration scenario
- Analytics dashboard

## Results

- Accuracy: **99.33%**
- Macro F1: **99.33%**
- Working fallback threshold: **0.40**
- Fallback rate: **2.69%**
- Errors captured: **10/11**
